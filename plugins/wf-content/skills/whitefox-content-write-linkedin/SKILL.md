# Write LinkedIn post

Writes one LinkedIn post for one kept `linkedin-post` angle. The goal is qualified interest
that leads readers to the case study or a conversation, with authority from specificity, not
hype.

## Read first

- `../whitefox-content-guide/formats/README.md`, then begin as it says (workspace, settings,
  campaign, profile).
- `../whitefox-content-guide/formats/draft.md` (the format).
- `../whitefox-content-house-style/SKILL.md`, all of it: rules, personas, evidence use,
  checklist.
- The campaign's `briefs/`, `lanes.md`, `quotes.md`, `shelf.md`, `keywords.md` (if it exists)
  and `drafts/`; the pool files of the proofs the angle uses.

## 1. Pick the angle

Kept `linkedin-post` angles with no live draft in `drafts/`. If the user names an angle, use it.
With several and none named, list them (ID, headline, persona) and ask which. If the chosen
angle already has a live draft, ask whether to write a new take; on yes, the old file is
archived when the new one is saved.

## 2. Write

- Voice: the angle's persona, exactly as house style describes it.
- Length: 110 to 180 words.
- Open with something concrete in the first two lines: the client's situation, a real detail
  from the build, or a lesson. No forced drama, no LinkedIn theatre.
- Short paragraphs, but not every sentence its own paragraph. One practical example, short list
  or diagnostic question if it helps.
- Evidence, claim level, quotes, flags and call to action: as in house style, "Using evidence
  in a draft". Every post has a lead route, even a soft diagnostic question.
- Keywords: one or two of the lane's phrases as natural topic anchors, never for density, never
  website meta copy.
- Hashtags: none, unless the user asks; then at most three specific ones.
- Run the house-style checklist. Fix what fails.

## 3. Show and approve

1. If the profile is not `approved`, say so first (checklist).
2. The post, ready to copy; its word count; "Built from"; the checklist.
3. Ask: "Reply **save**, or tell me what to change, for example: *shorter*, *open with a
   detail from the build*, *switch to the founder voice*." Apply changes and show the post again.
4. On yes: if this is a new take, rename the old file to
   `ANGLE-nn-linkedin-post-archived-<YYYY-MM-DD>.md`. Save
   `drafts/ANGLE-nn-linkedin-post.md` in the format, status `draft`, `written_by` the user's
   name.

## Change a draft's status

If the user asks to mark a draft `approved`, `published` or `archived` (for example "mark
ANGLE-03 published"), show its current status, change the `status` line after a yes, and stop.

## Rules

- Nothing is saved before the user's yes.
- No claim beyond the angle's proofs and claim level.
